# Mode: compare

Compare two programs side by side.

```bash
uplanner compare <id-a> <id-b> --json
```

Missing facts are labelled `Not verified`, `Verify on program page` or `—`.
Never fill a gap with an assumption. Explain that CTC, MEP, base salary and
guaranteed compensation are not interchangeable, and that a cohort median is
not a personal outcome.

End with the decision the user must make; do not make it for them.
