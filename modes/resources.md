# Mode: resources

Find free learning resources by domain.

```bash
uplanner resources --domain ai,data --limit 8 --json
```

Domains: `ai`, `data`, `finance`, `wm`, `cloud`, `product`, `sc`, `lead`,
`entre`, `program`, `design`, `sec`, `growth`.

The output is already filtered to free resources. Present the title, format,
duration and URL. Add the editorial note where it explains why the resource
matters. Never substitute a paid alternative and never add affiliate links.

If no resources match, ask which domain or skill the user wants rather than
inventing one.
