# Mode: degree-plan

Rank programs from the researched directory by evidence strength and priority.

```bash
uplanner degree-plan --country India --group "MBA / management" --limit 12 --json
```

Every row carries its evidence label, research tier, next recorded round and
the reasons for its score. Program facts come only from generated content.

Never invent or "improve" a deadline. If no round is recorded, show `—` and
say the 2027 cycle needs official verification. Tier 1/2/Backup grouping is a
planning decision for the user; suggest dropping a program when the evidence
and cost do not justify an application, but never decide silently.
